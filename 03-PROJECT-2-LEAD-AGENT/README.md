# AI Lead Classification Agent

## Project Overview

This project is an AI-powered Lead Classification Agent built as part of my 30-Day AI Builder Journey.

The goal is to classify incoming course leads into categories and priority levels using an LLM.

## Current Features

- Lead classification using an LLM
- Structured JSON output
- SOC, VAPT, Desktop, and Other categories
- Hot, Warm, and Cold priority levels
- Classification rules
- Prompt examples
- Testing with dummy leads
- Recommended next actions
- Draft replies

## Technology Used

- Python
- Ollama
- Llama 3
- JSON
- CSV
