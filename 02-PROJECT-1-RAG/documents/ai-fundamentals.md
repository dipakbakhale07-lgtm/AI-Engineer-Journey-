# AI Fundamentals

## What is Artificial Intelligence?

Artificial Intelligence (AI) refers to the development of computer systems capable of carrying out tasks that typically demand human intelligence.

Common examples include:

- Interpreting natural language
- Identifying objects in images
- Forecasting outcomes
- Detecting patterns in large datasets
- Making informed decisions

## What is Machine Learning?

Machine Learning (ML) is a subset of AI in which systems learn from data rather than relying on predefined rules or explicit programming.
A typical machine learning setup involves:

- Data for learning
- Features or data representations
- A learning algorithm

- A resulting trained model
- New data used to generate predictions
## What is Deep Learning?
Deep Learning is a specialized form of machine learning that relies on neural networks with many layers to capture intricate patterns in data.
It is widely applied in areas such as:
- Visual recognition
- Voice and speech processing
- Understanding and generating human language
- Creating new content through generative models
## The Relationship Between AI, Machine Learning, and Deep Learning
These fields are connected hierarchically:
AI
↓
Machine Learning
↓
Deep Learning
AI is the overarching domain.
Machine Learning is one method used within AI.
Deep Learning is a specific technique within Machine Learning, based on layered neural networks.
## Key Concepts
### Model
A model is a computational system that has been trained to recognize patterns and make predictions or generate outputs.
### Training
Training is the process by which a system learns from data, adjusting its internal parameters to improve performance.
### Inference
Inference refers to applying a trained model to new, unseen data in order to produce a result or prediction.

### Dataset
A dataset is a structured collection of data used for training models, evaluating their performance, or conducting analysis.
