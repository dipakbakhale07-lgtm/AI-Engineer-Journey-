# RAG Evaluation Template

## Purpose

This template is used to evaluate the RAG Knowledge Assistant systematically.

The goal is to measure whether the system:

- Retrieves relevant information
- Produces answers supported by the documents
- Refuses unsupported questions
- Handles tricky or near-miss questions correctly
