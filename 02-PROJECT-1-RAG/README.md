# Project 1 - RAG Knowledge Assistant

## 🎯 Project Goal

Build a document based AI assistant, which will respond to questions asked by users based on information contained within the provided, approved knowledge documents.

The solution should prioritize information found in the documents over the LLM's general knowledge.

## Core RAG Flow

Documents
↓
Document Processing
↓
Chunks
↓
Embeddings
↓
Vector Store
↓
Retrieval
↓
LLM
↓
Grounded Answer

## Main Features

- Accepting knowledge documents

- Processing their contents
- Chunks creation from the documents
- Embeddings creation
- Saving embeddings in a vector store
- Querying for relevant information
- Providing the information to the LLM
- Generating an answer
- Preventing hallucination when information is not found in provided documents

## Project Focus
The focus of the project is on learning and implementing the following areas:
- RAG
- Document processing
- Chunking
- Embeddings
- Vector stores
- Retrieval
- LLM
- Grounded generation
- Source aware answering
