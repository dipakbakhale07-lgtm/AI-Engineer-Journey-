---

## 5 Things I Learned

1. How a complete RAG pipeline works from documents to a grounded answer.

2. Document chunking helps break large documents into smaller searchable pieces.

3. Embeddings and similarity search help find information relevant to a user's question.

4. Retrieved context helps ground LLM answers in the provided knowledge documents.

5. Building an AI project also involves testing, documentation, user experience, and demonstrating the final system.

---

## 3 Things I Would Improve Later

1. Support more document formats such as PDF and DOCX.

2. Improve retrieval accuracy using more advanced chunking and retrieval techniques.

3. Add stronger evaluation and testing for answer quality and retrieval performance.

---

## Reflection

Building the RAG Knowledge Assistant helped me understand RAG practically instead of only learning the theory.

I learned how different components such as document processing, chunking, embeddings, similarity search, retrieval, and LLM generation work together in one AI application.

This is Version 1 of the project.

It is a learning project and is not claimed to be production-ready.
