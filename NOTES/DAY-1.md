## Git & GitHub

### What I learned

- Git tracks changes and maintains the history of a project (repository)

- GitHub offers remote hosting for our repository

- The local repository and the GitHub repository can have different histories and therefore need to be merged carefully and deliberately.

### Commands I used

```text

git init

git status

git log --oneline --decorate -5

git remote -v
