# Day 17 — Project 3: AI Social Media Assistant

## Goal

Build a system that helps create useful social media posts, not spam.

## Target Audience

The target audience is:

- Builders interested in AI
- Clients interested in AI
- People interested in freelancing
- People interested in Python projects

## Four Post Types

### 1. What I Learned

Share a useful concept or lesson learned during the AI Engineer journey.

### 2. What I Built

Share a real project, feature, or result that was actually built.

### 3. What Failed

Share a real problem, error, unsuccessful approach, and the lesson learned from it.

### 4. Simple Explainer

Explain an AI, Python, or technical concept in simple language.

## Content Purpose

Every planned post must have a useful reason to exist.

The content should provide:

- A useful lesson
- A project insight
- A real learning experience
- A simple technical explanation

Generic motivational content should be avoided.

## Human Approval Rule

There will be no automatic publishing.

The workflow is:

Content Idea
↓
AI prepares a draft
↓
Human reviews the draft
↓
Human edits if necessary
↓
Human approves
↓
Manual publishing

The AI prepares the draft, but the human makes the final publishing decision.

## Source Checking

Before publishing, check that the content is based on:

- Actual learning
- Actual projects
- Actual experiences
- Accurate technical information

The system should not invent achievements, projects, results, or experiences.

## Content Tracker

A content tracker is maintained to organize planned posts.

The tracker records:

- Post ID
- Post Type
- Topic
- Purpose
- Source/Experience
- Draft Status
- Human Approved
- Published

## Day 17 Self-Check

For every planned post, ask:

"Does this post have a useful reason to exist?"

If the answer is no, the post should not be created or published.

## Key Lesson

The purpose of an AI Social Media Assistant is not to generate as many posts as possible.

The purpose is to help create relevant, useful, and genuine content while keeping human approval in the workflow.
