# DAY 18 — Create a Content Input System

## Goal
Feed the Social Media Assistant reliable material.

## What I Learned

### 1. Content inputs
A content input is structured information that the assistant can use to prepare a post.

Instead of asking AI to invent a post from nothing, we provide real information from our Builder Log and project work.

### 2. Main source
The main source should be my own Builder Log.

Other useful source material can include:
- Notes
- Project logs
- URLs
- Screenshots

The important point is to keep the source of the information clear.

### 3. Required fields
Each content input contains:

- topic
- source_notes
- audience
- key_lesson
- call_to_action

### 4. Accuracy rule
AI must not invent an experience that I did not have.

Every content input should be based on something I actually did or learned.

### 5. Project-based inputs
For Day 18, the content inputs are created from my actual work in:

- Project 1 — RAG Knowledge Assistant
- Project 2 — AI Lead Qualification Agent

## What I Practiced

I created five structured content inputs using the required fields.

The inputs are intended to give the future drafting pipeline reliable material instead of allowing the AI to invent experiences.
