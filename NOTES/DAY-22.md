→ Approval

## Project 3 Demo

The interface demonstrates:

- Home dashboard
- Content creation
- AI content generation
- Draft management
- Human review
- Quality checklist
- Approval workflow

The system does not automatically publish content.

Publishing remains a manual human decision.

## Human Review

The review process checks:

- Is it true?
- Is it useful?
- Is there any private information?
- Is there any secret or API key?
- Is there any exaggerated claim?

The workflow is:

DRAFT → REVIEW → APPROVED → POSTED

### What I Built

This week I worked on Project 3 — SocialAI Assistant.
