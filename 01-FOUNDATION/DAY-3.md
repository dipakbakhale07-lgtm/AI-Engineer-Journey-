# 1. 🎯 Day 3 Objective

The goal of Day 3 is not simply to write more Python code.

The main objective is to understand how to work with AI-generated and AI-assisted code effectively.

AI can generate code very quickly, but generated code is not automatically correct.

An AI Engineer should be able to:

- Read the generated code
- Understand what each part does
- Identify inputs and outputs
- Understand functions and conditions
- Read error messages
- Find the source of an error
- Fix the problem
- Test the fix
- Verify that the final result is correct
- Explain the solution in their own words

The main principle for today's work is:

> AI can assist with coding, but the engineer is responsible for understanding, testing and validating the result.

---

# 2. 🤖 AI-Assisted Coding

AI-assisted coding means using AI tools to help with software development.

An AI assistant can help with:

- Generating a first version of code
- Explaining unfamiliar code
- Suggesting improvements
- Finding possible bugs
- Explaining error messages
- Creating examples
- Generating test cases
- Refactoring code
- Writing documentation

However, generated code should not automatically be considered correct.

A useful workflow is:

```text
Problem
   ↓
Ask AI / Create Solution
   ↓
Read the Code
   ↓
Understand the Logic
   ↓
Run the Code
   ↓
Check the Output
   ↓
Find Errors
   ↓
Fix
   ↓
Test Again
