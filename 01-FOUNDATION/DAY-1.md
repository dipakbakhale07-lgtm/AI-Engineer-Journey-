What did I learn?
1. When Git reports an error, the first thing to do is confirm your current working directory.
2. Ensure the destination directory where you are cloning the repository is available.
3. Determine whether the destination folder is a Git repository.
4. Check if Git remote is set up correctly.
5. Confirm whether you have permission to work with the repository.
6. Execute “ git status” command to detect the status of the Git repository.
7. Run the –v command to display more information about the remote repository. ✅
